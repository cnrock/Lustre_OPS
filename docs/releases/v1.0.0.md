# Lustre OPS v1.0.0

`v1.0.0` 是 Lustre OPS 首个公开托管版本，提供面向 Lustre 并行文件系统的中文监控、巡检、告警和 AI 日志诊断工作台。

## 版本亮点

- 云控制台态势首页：统一呈现文件系统、容量、吞吐、IOPS、告警和 MDS/OSS/客户端/LNet 状态。
- 多维监控：性能趋势、OST/MDT 容量、inode、容量预测、节点指标和网络质量。
- 真实巡检：执行 Lustre/Linux 检查命令，动态展示阶段、命令、输出、退出码和结论。
- 告警闭环：支持告警队列、详情证据、处置步骤和大模型辅助分析。
- AI 日志诊断：异常日志优先、多轮对话、历史会话、模型配置和连接测试。
- 智能体知识库：故障案例、文档上传、分块解析、版本管理、向量召回、检索测试和反馈权重。
- 中文生产工具 UI：覆盖加载、空、成功、错误、深色和窄屏状态，并接入 ImageGen 空状态视觉。

## 验证结果

- `npm run build`：通过。
- `npm run lint`：通过，保留 61 个动态 API 类型警告，无错误。
- 后端单元测试：5 项通过。
- 测试服务器：API 服务正常，UI 与 3 项 WebP 视觉资源返回 200。
- 浏览器验收：主要页面、按钮、弹窗、知识库、日志对话、深色和窄屏场景已完成 smoke test。

## 安全与适用范围

该版本适合测试环境、实验集群和二次开发。当前尚未内置完整登录/RBAC、分布式 Agent、生产级向量数据库和 WSGI 部署能力。请在受控管理网络中使用，通过反向代理补充 TLS 与身份认证，并始终由管理员审核后人工执行影响存储数据的操作。

完整说明见 [README](https://github.com/jiaguangqi/Lustre_OPS/blob/v1.0.0/README.md)、[部署指南](https://github.com/jiaguangqi/Lustre_OPS/blob/v1.0.0/docs/deployment.md)、[安全说明](https://github.com/jiaguangqi/Lustre_OPS/blob/v1.0.0/SECURITY.md)和[更新日志](https://github.com/jiaguangqi/Lustre_OPS/blob/v1.0.0/CHANGELOG.md)。
