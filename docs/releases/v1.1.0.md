# v1.1.0 - 2026-10-10

在 v1.0.0 基础上适配真实 Lustre 环境，并补齐账户与权限能力。

## 修复

- **巡检崩溃 `int(None)`**：无 OST 数据时 `max_ost` 为 `None` 导致 `int(None)` 抛错、巡检「执行失败」。改为安全取值。
- **挂载点硬编码 `/lustre/client`**：后端约 25 处、前端多处写死 `/lustre/client`，与实际挂载点 `/lustre` 不符，导致挂载检查、`lfs df` 全部失败。改为读取 `LUSTRE_CLIENT_MOUNT`（默认 `/lustre/client`）。
- **缺表 `no such table`**：启动时新增 `ensure_metrics_tables()` 自动创建 `ost_metrics` / `perf_rates` / `node_metrics` / `alerts` / `health_checks` 等表。
- **巡检无历史**：新增 `health_check_runs` 表保存每次巡检完整快照；巡检页改为手动触发。

## 新增

- 登录鉴权与会话令牌（角色 admin / engineer / viewer）。
- 前端登录页 `Login.tsx` + 请求自动带令牌。
- 用户管理（后端 CRUD + 前端对接）。
- 巡检历史（列表 / 查看 / 删除，接口 `GET /api/health-check/history` 等）。

## 变更

- 挂载点、数据库路径等改为环境变量可配置（见 `CHANGES_CN.md`）。

## 部署

- 必须设置 `LUSTRE_CLIENT_MOUNT=/lustre`（systemd 内用 `Environment=` 持久化）。
- 前端需重新构建后重启。
