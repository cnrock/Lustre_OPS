# v1.2.0 - 2026-10-10

全集群真实监控改造：推送式多节点采集 + 告警规则引擎 + 飞书推送，前端全面接入真实后端。

## 新增

- **推送式多节点采集**：`app/api/lustre_collect.py`（采集核心）+ `app/api/lustre_agent.py`（节点 agent）。每个节点本机执行只读命令并 `POST /api/ingest/report`，无需后端 SSH 到各节点。
- **后端自采集**：后端节点默认自动采集本机 Lustre（`LUSTRE_SELF_COLLECT`、`LUSTRE_COLLECT_INTERVAL`）。
- **告警规则引擎** `app/api/lustre_alerts.py`：规则存库、去重、自动闭环，支持飞书 Webhook 推送。
- **客户端连接故障检测**：解析 `lfs check` 报错（transport endpoint shutdown / I/O error），按 target 分别告警。
- **内核错误签名检测**：从内核日志提取 Lustre/LNet 严重错误签名。
- **每条告警附带处理指引**：可能原因 + 定位步骤 + 处理建议。
- 新增接口：`/api/ingest/report`、`/api/nodes`、`/api/cluster/config`、`/api/alert-rules`、`/api/notification-channels`、`/api/notify/test`。

## 变更

- **前端接真实后端**：告警管理页与集群配置页移除 mock，读取真实 API；告警页 30s 自动刷新。
- 新增前端 API 客户端 `src/lib/cluster.ts`、映射 `clusterMap.ts`、状态 `clusterStore.ts`。
