# v1.3.0 - 2026-10-10

容器化部署：DaemonSet 全节点采集 + 前后端一体化镜像 + 完整 K8s 清单。

## 新增

- **采集 Agent DaemonSet** `deploy/agent/`：每个 Lustre 节点一个 Pod，以 `hostPID + privileged` 运行，通过 `nsenter -t 1 -m -u -i -n -p` 进入宿主机命名空间执行 `lfs`/`lctl`/`lsmod`/`journalctl`。`tolerations: operator: Exists` 保证被 cordon / GPU 污点的节点也被覆盖。
- **一体化后端镜像** `deploy/server/Dockerfile`：Flask API + 前端静态资源同容器；`hostPID + privileged` 使后端节点也能自采集。
- **K8s 清单**：`deployment.yaml`（Deployment + PVC + NodePort Service）、`daemonset.yaml`（Secret + DaemonSet）。
- **SPA 静态托管**：后端兼容 `/` 与 `/lustre-ops/` 前缀及前端路由回退。
- **agent 常驻循环模式** `LUSTRE_AGENT_LOOP`；采集器 `LUSTRE_NSENTER` / `LUSTRE_NODE_NAME`。

## 变更

- 采集器读 `/proc/fs/lustre/*` 改为经 nsenter，保证容器内读到宿主机数据。

## 部署

```bash
docker build -t <registry>/lustre-ops-agent:latest -f deploy/agent/Dockerfile app/api
docker build -t <registry>/lustre-ops:latest -f deploy/server/Dockerfile .
kubectl apply -f deploy/server/deployment.yaml
kubectl apply -f deploy/agent/daemonset.yaml
```
