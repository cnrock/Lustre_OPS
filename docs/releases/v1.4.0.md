# v1.4.0 - 2026-10-10

集群清单对账：登记应采集节点，自动比对实际上报节点，发现漏报与掉线。

## 新增

- **集群清单** `deploy/inventory.json`：8 个 MDS/OSS 服务端（管理 IP + 双口 LNET）、4 台 ES400NVX2 存储阵列（管理网 + BMC）、3 个网段与客户端 LNET 段。
- **对账接口** `GET /api/inventory`：比对「应有节点」与「实际上报节点」。
- **节点存活看门狗**：心跳超时（默认 300s，`LUSTRE_NODE_STALE_SECONDS`）→ critical「疑似掉线」；清单应有但从未上报 → critical「未上报采集」。
- **前端「清单对账」标签页** + **ConfigMap** `inventory-configmap.yaml`。

## 修复

- 修正客户端 / 服务端 LNET 地址段区分（客户端 203.0.113.3–.34、服务端 203.0.113.100–.115）。
