# v1.5.0 - 2026-10-10

依据 **DDN LustreFS 操作手册 v0.3** 新增服务端深度探针，仅在 MDS/OSS 节点生效。

## 新增

- **服务端深度探针** `app/api/lustre_server_probe.py`：
  - Recovery 状态（`/proc/fs/lustre/mdt/*/recovery_status`、`/proc/fs/lustre/obdfilter/*/recovery_status`）。
  - DDN `check_servers.pl` / `get_ost.pl`。
  - IB HCA（`ibstat`）：mlx5_* 端口是否 ACTIVE/LinkUp、速率。
  - DDN 磁盘数（`lsscsi | grep -c DDN`）：MDS/OSS=6、OSS=4。
  - LDLM 锁数量（`ldlm.namespaces.*.lock_count`）。
  - HA（`rg_control status`）：在线节点与资源组。
- **4 条服务端告警规则**（含处理指引）：Recovery 未完成、Target DOWN、IB 端口未 LinkUp、DDN 磁盘数不足。
- **落库** `server_probes` 表 + 查询接口 `/api/server-probes`。
- **前端「服务端探针」标签页**。

## 变更

- 采集器 `collect_report` 增加 `server_probe` 字段。
