# v1.6.0 - 2026-10-11

修复客户端挂载点误判，恢复容量、OST 与性能数据。

## 修复

- **客户端挂载点误判「未挂载」**：后端挂载点默认 `/lustre/client`，与实际挂载点
  `/lustre` 不一致时，`os.path.ismount()` 返回 False，导致总览误判「Lustre 文件系统
  当前未挂载」，且容量、OST、性能数据全部显示「无数据」——而 `lfs check` 实际全部 active。
  现改为**自动探测真实挂载点**：优先使用 `LUSTRE_CLIENT_MOUNT`，其未挂载时回退
  `findmnt -t lustre -o TARGET` 的探测结果。
- 状态接口 `/api/lustre/status`、巡检流程、采集与容量接口统一使用探测后的挂载点。

## 变更

- 新增 `detect_lustre_mount()` / `lustre_mounted()`，集中处理挂载点解析与挂载判定。

## 部署

- 仍建议显式设置 `LUSTRE_CLIENT_MOUNT=/lustre`；即使未设置，也会自动探测到真实挂载点。
