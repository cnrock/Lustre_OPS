# v1.7.0 - 2026-10-11

全新界面改版：参考 Apple 官网审美重构设计系统。功能与接口不变。

## 新增

- **设计系统重构**（`src/index.css` 设计令牌 + `tailwind.config`）：
  - 配色：Apple 蓝 `#0071e3` 主色，近黑 `#1d1d1f` 正文，`#fbfbfd` 浅底。
  - 版式：大留白、精确负字距（`-0.011em` / 标题 `-0.022em`）、数字等宽。
  - 层次：柔和多层阴影（`ops-card`）、毛玻璃导航（`ops-glass`）。
  - 圆角：统一 14px 半径体系；按钮采用胶囊圆角。
- **登录页**：居中卡片 + 柔和光晕背景 + 胶囊主按钮。
- **侧边导航**：毛玻璃面板、分组标题、圆角高亮当前项。
- **顶栏**：毛玻璃 + 胶囊搜索框 + 圆形图标按钮。
- **总览页**：统一卡片、指标块与状态徽章到新设计令牌。

## 变更

- 浅色为主、深色为精致对偶（黑底 + `#0a84ff` 强调色）。
- 保留全部功能与信息密度，未改动任何接口或数据逻辑。

## 部署

- 前端重新构建即可：`cd app && npm ci && npm run build`，随后重启容器/Pod。
