# v1.8.0 - 2026-10-11

界面改版覆盖全部模块，并引入应用版本单一来源。功能与接口不变。

## 新增

- **全模块界面统一**：在 v1.7.0 基础上，将告警、告警详情、巡检、文件系统、
  日志、设置、报表、容量、性能、网络等页面全部迁移到 Apple 风格设计系统
  （设计令牌、毛玻璃导航、胶囊按钮、柔和层次阴影、统一圆角）。
- **应用版本单一来源** `src/lib/version.ts`（`APP_VERSION` / `APP_VERSION_LABEL`），
  侧边导航与登录页统一展示当前版本，避免版本号散落各处。

## 变更

- 移除各页硬编码的旧调色板（slate/blue 十六进制），统一由设计令牌驱动深浅色。
- README 版本历史改为**倒序**（最新在上、v1.0.0 置底）。

## 部署

- 前端重新构建：`cd app && npm ci && npm run build`，随后重启容器/Pod。
