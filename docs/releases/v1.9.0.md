# v1.9.0 - 2026-10-11

客户端部署适配 + 真实版本探测 + 简化部署。功能对齐"只在客户端部署"的约束。

## 新增

- **客户端部署适配**：新增 `serverMode: client-only`（清单或环境变量 `LUSTRE_SERVER_MODE`）。
  服务端不部署 agent 时，看门狗不再把清单中的服务端判为"应报未报"，并清理历史误报。
- **Target DOWN / Recovery 客户端判定**：无服务端 agent 时，改用客户端
  `check_servers.pl -v` + `lfs check` 间接判定 MDT/OST 的 OK/DOWN 与 recovery，
  覆盖"服务端 target 是否挂掉"这一最关键故障。
- **真实版本探测**：Lustre 客户端版本由 `lctl get_param -n version` 真实读取
  （`collect_versions()`），总览页同时展示**服务端**与**客户端**两个版本。
  服务端版本优先取服务端 agent 上报值，其次清单 `serverVersion` 声明。
- **服务端探针优雅降级**：无数据时给出说明（客户端模式）而非报错。

## 变更

- 部署清单改用官方镜像 `cnrock/lustre-ops:1.9.0` / `cnrock/lustre-ops-agent:1.9.0`。
- 重写部署指南：客户端 / 全量两种模式、组件交互图、他人复现步骤。

## 部署

官方镜像已发布到 Docker Hub（`cnrock`），无需自建：

```bash
kubectl apply -f deploy/server/inventory-configmap.yaml
kubectl apply -f deploy/server/deployment.yaml
kubectl apply -f deploy/agent/daemonset.yaml
```
