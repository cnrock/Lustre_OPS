# v1.9.1 - 2026-10-14

镜像基础镜像升级 + 内置 curl。功能与 v1.9.0 完全一致，属可平滑升级的维护版本。

## 变更

- **基础镜像升级到 Python 3.12**：server / agent 镜像均改用 `python:3.12-slim`。
  - 选用 3.12 slim 的原因：3.12 是当前受支持且生态稳定的版本，slim 变体体积小、攻击面小；
    既避开 3.13 早期版本的部分三方轮子缺口，也避免长期停留在即将 EOL 的 3.11 基线上。
  - 本项目依赖极轻（Flask + flask-cors）且为纯 Python，3.11 → 3.12 无需改代码。
- **内置 curl**：两个镜像都安装 `curl`，方便容器内健康检查、探针和现场排障
  （例如 `kubectl exec ... -- curl -s localhost:3006/api/health`），无需再临时装包。
- 部署清单镜像 tag 更新到 `1.9.1`：`cnrock/lustre-ops:1.9.1` / `cnrock/lustre-ops-agent:1.9.1`。
- 前端应用版本号同步为 `1.9.1`（`src/lib/version.ts`、`package.json`）。

## 镜像

已发布到 Docker Hub 官方仓库，**多架构（linux/amd64 + linux/arm64）**：

```
cnrock/lustre-ops:1.9.1          # 后端一体化（API + 前端 + 自采集）
cnrock/lustre-ops-agent:1.9.1    # 节点采集 Agent（DaemonSet）
```

## 部署

```bash
kubectl apply -f deploy/server/inventory-configmap.yaml
kubectl apply -f deploy/server/deployment.yaml
kubectl apply -f deploy/agent/daemonset.yaml
```

自 v1.9.0 升级：仅需把清单里的 image tag 改为 `1.9.1` 并重新 `kubectl apply`，
数据卷（`/data` SQLite）与配置不变。
